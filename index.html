Sketchboard 사용법

손그림 느낌의 브레인스토밍 보드입니다. 인터넷 없이 이 파일 하나로 동작하고, 모든 내용은 브라우저에 자동 저장됩니다.

1~9 0도구 전환 — 선택 · 손바닥 · 사각형 · 마름모 · 원 · 화살표 · 선 · 펜 · 텍스트 · 메모
V H R D O A L P T N E같은 도구의 영문 단축키 (지우개는 E)
Space + 드래그캔버스 이동 (손바닥 도구와 같음)
휠 / 트랙패드 핀치확대 · 축소 (모바일은 두 손가락으로 확대)
스타일 패널 › 글꼴고딕 · 손글씨 · 고정폭 · 굵은제목 · 또박손글씨 · 명조 · 둥근체 · 도트체 8종 중에서 고름 (선택한 요소에 적용, 없으면 새 요소 기본값)
스타일 패널 › 글꼴 크기선택한 요소(없으면 새 요소 기본값)의 글자 크기를 작게 · 보통 · 크게 · 특대로 바꿈
더블클릭글자 수정 · 빈 곳이면 새 텍스트 (카드의 제목·메모도 같은 방식)
Ctrl/Cmd + C / X / V선택한 요소 복사 · 잘라내기 · 붙여넣기 (붙여넣으면 조금씩 비켜 놓이고, 이어서 누르면 계속 쌓입니다 · 한글 자판도 동작)
Ctrl/Cmd + A보드의 모든 요소 선택
Ctrl/Cmd + V이미지 붙여넣기 · 유튜브나 웹 주소를 붙여넣으면 카드가 생깁니다 (복사해 둔 요소가 있으면 그것을 먼저 붙입니다)
사진 · 유튜브 · 링크우측 상단 추가 버튼에서 넣거나, 이미지 파일을 캔버스로 끌어다 놓아도 됩니다
Ctrl/Cmd + Z실행 취소 (Shift 함께 누르면 다시 실행)
Delete / Backspace선택한 요소 삭제
Ctrl/Cmd + D복제 (스타일 패널의 복제 버튼으로도 됩니다)
Shift + 클릭여러 개 선택
Shift + 1 / Shift + 0전체 보기 / 100%
Shift + G / Shift + D그리드 / 다크 모드
Tab 또는 패널 헤더 ‹스타일 패널 접기 · 펴기 (접으면 캔버스가 넓어지고 좌상단 스타일 버튼으로 다시 엽니다)
편집 중 Enter목록 자동 이어쓰기 — 1. ㄱ. 가. a. - [ ] 로 시작한 줄은 다음 번호·기호가 자동으로 붙고, 빈 항목에서 한 번 더 누르면 목록이 끝납니다
Esc편집 끝내기 · 선택 해제
